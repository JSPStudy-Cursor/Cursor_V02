사용자가 키워드를 입력하면 비디오를 찾아주고, 카테고리나 정렬 기준에 맞춰 결과를 보여주는 기능을 만들고 싶어. 아래 조건에 맞춰서 코드를 작성해줘.
➀ 라우트 설정: main 블루프린트에 /search 주소를 만들어줘. (데이터를 가져오는 것이니 GET 방식을 사용해줘.)
➁ 검색어 및 옵션 처리: 사용자가 입력한 검색어(q), 선택한 카테고리(category), 정렬 방식(sort), 현재 페이지 번호(page) 파라미터를 받아줘. 페이지 번호는 기본값을 1로, 정수(int) 타입으로 처리해줘.
➂ 복합 쿼리 구성 (SQLAlchemy 사용):
- 검색어(q)가 있으면: 비디오의 제목(title)이나 설명(description)에 검색어가 포함되어 있는지 검사해줘 (ilike 사용).
- 카테고리(category)가 있고 '전체'가 아니면: 해당 카테고리의 비디오만 필터링해줘.
- 정렬(sort) 기준 처리: '최신순'이면 최신 등록일순, '인기순'이면 좋아요(likes) 개수순, '조회수순'이면 views가 높은 순으로 정렬해줘.
➃ 페이지네이션 적용: paginate(page=page, per_page=12, error_out=False)를 사용해 한 페이지에 12개씩 보여주고, 결과를 main/search.html로 보내줘.

1. 사용자 프로필 (GET /user/<username>)
➀ 라우트 및 사용자 조회: main 블루프린트에 /user/<username> 주소를 만들어줘. URL에 있는 username으로 사용자를 조회하고, 만약 없는 사용자라면 404 에러를 띄워줘 (first_or_404 사용).
➁ 비디오 목록: 해당 사용자가 업로드한 비디오들을 최신순으로 정렬해서 가져와줘.
➂ 통계 데이터 계산: 데이터베이스 집계 함수를 사용하거나 관계를 활용해서, 이 사용자의 '총 비디오 수', '모든 비디오의 누적 조회수 합계', '모든 비디오의 누적 좋아요 합계', 그리고 이 사용자의 '구독자 수(subscribers)'를 계산해서 화면에 함께 전달해줘.
➃ 화면 표시: main/profile.html 템플릿을 호출해줘.

2. 구독 피드 (GET /subscriptions)
➀ 라우트 설정: main 블루프린트에 /subscriptions 주소를 만들어줘.
➁ 데이터 조회: 현재 로그인한 유저(세션 또는 임시 유저 개념 사용 가능)가 구독(follow)하고 있는 크리에이터들의 비디오만 필터링해서, 최신순으로 정렬하여 가져와줘. (N:M 구독 관계 테이블을 활용한 JOIN 또는 서브쿼리 사용)
➂ 화면 표시: main/subscriptions.html 템플릿에 데이터를 담아 렌더링해줘.

웹과 모바일 앱에서 데이터를 사용할 수 있도록 REST API와 관련 동영상 추천 기능을 만들고 싶어. 아래 조건에 맞춰서 코드를 작성해줘.

1. 비디오 API와 추천 알고리즘 (api 블루프린트)
➀ 비디오 목록 (GET /api/videos): 사용자가 page, per_page, sort, category, search 파라미터를 보낼 수 있게 해줘. SQLAlchemy의 paginate() 메서드를 활용하여 페이지 기반 페이지네이션을 구현해줘.
➁ JSON 응답 형식: 응답은 jsonify를 사용해서 아래와 같은 구조의 JSON 규격으로 반환해줘.
{
  "videos": [ {"id": 1, "title": "비디오 제목", ...}, ... ],
  "total": 100,
  "page": 1,
  "pages": 9
}
➂ 비디오 상세 및 추천 시스템 (GET /api/videos/<int:video_id>): 지정된 비디오 정보를 가져옴과 동시에, 해당 비디오와 연관된 '추천 동영상(Related Videos)' 목록 4개를 같이 골라내어 JSON 하나로 묶어 반환해줘.
- 추천 알고리즘 규칙:
  1순위: 현재 비디오와 동일한 '태그(Tag)'를 가장 많이 공유하는 비디오 목록 (다대다 태그 테이블 활용)
  2순위: 같은 '카테고리(Category)'에 속한 비디오
  3순위: 같은 '작성자(User)'가 올린 다른 비디오 순으로 우선순위를 두어 쿼리를 조합해줘. (현재 보고 있는 비디오는 추천 목록에서 제외할 것)

2. 태그 및 사용자 API
➀ 태그 목록 (GET /api/tags): 데이터베이스에 등록된 전체 태그 목록과 각 태그별 연결된 비디오 숫자를 집계하여 JSON 배열로 반환해줘.
➁ 사용자 정보 (GET /api/users/<int:user_id>): 특정 사용자의 프로필 기본 정보 및 업로드한 비디오 요약 목록을 JSON으로 반환해줘.
