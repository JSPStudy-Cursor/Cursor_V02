6.1
프롬프트1 : Flask로 유튜브 같은 비디오 시청 기능을 만들고 싶어. 아래 조건에 맞춰서 코드를 작성해줘.
➀ 라우트 설정: main 블루프린트에 /watch/<int:video_id> 주소를 만들어줘.
➁ 데이터 불러오기: 데이터베이스에서 video_id에 해당하는 비디오를 찾고, 만약 없으면 404 에러 페이지를 보여줘. (Video.query.get_or_404 사용)
➂ 조회수 기능: 사용자가 이 페이지에 들어올 때마다 비디오의 조회수(video.views)를 1씩 올리고 DB에 저장해줘.
➃ 화면 표시: main/watch.html 파일을 템플릿으로 사용하고 비디오 정보를 넘겨줘.
➄ 플레이어 제작: watch.html 안에는 HTML5 <video> 태그를 넣어줘. 영상 주소는 video.get_video_url()을 쓰고, 썸네일은 poster 속성으로 나오게 해줘.

프롬프트2 : 지금 만든 기능을 단위테스트 코드를 작성해서 확인해줘

프롬프트3 : 현재 templates/에 있는 HTML 파일들과 static/에 있는 CSS, JS 파일들을 방금 만든 Flask 백엔드 기능과 연결해줘.

6.2
프롬프트1 : 사용자가 키워드를 입력하면 비디오를 찾아주고, 카테고리나 정렬 기준에 맞춰 결과를 보여주는 기능을 만들고 싶어. 아래 조건에 맞춰서 코드를 작성해줘.
➀ 라우트 설정: main 블루프린트에 /search 주소를 만들어줘. (데이터를 가져오는 것이니 GET 방식을 사용해줘.)
➁ 검색어 및 옵션 처리: 사용자가 입력한 검색어(q), 선택한 카테고리(category), 정렬 방식(sort), 현재 페이지 번호(page) 파라미터를 받아줘.
페이지 번호는 기본값을 1로, 정수(int) 타입으로 처리해줘.
➂ 복합 키워드 검색: SQLAlchemy의 or_와 ilike를 활용해줘.
비디오 제목(Video.title)이나 설명(Video.description) 중 하나라도 검색어가 포함되어 있다면 결과에 포함해줘.
➃ 카테고리 필터: 사용자가 특정 카테고리를 선택했다면(값이 있다면), 해당 카테고리와 일치하는 영상만 필터링해서 보여줘.
➄ 동적 정렬 기능: 사용자가 선택한 sort 값에 따라 결과 순서를 바꿔줘.
- latest: 최신순 (등록일 내림차순)
- popular: 인기순 (좋아요 또는 평점 내림차순)
- views: 조회수순 (조회수 내림차순)
➅ 페이지네이션 및 전송: 한 페이지에 영상이 12개씩 나오도록 paginate를 적용해줘.
결과물인 videos 객체와 함께, 사용자가 입력했던 q, category, sort 값을 main/search.html 템플릿으로 모두 넘겨줘. (검색창에 입력값이 유지되게 하려고 해.)

프롬프트2 : 지금 만든 기능을 단위테스트 코드를 작성해서 확인해줘

프롬프트3 : 현재 templates/에 있는 HTML 파일들과 static/에 있는 CSS, JS 파일들을 방금 만든 Flask 백엔드 기능과 연결해줘.



6.3
프롬프트1 : 사용자의 상세 정보를 보여주는 프로필 페이지와, 내가 구독한 채널의 영상만 모아보는 피드 기능을 만들고 싶어. 아래 조건에 맞춰서 코드를 작성해줘.
1. 사용자 프로필 (GET /user/<username>)
➀ 라우트 및 사용자 조회: main 블루프린트에 /user/<username> 주소를 만들어줘. URL에 있는 username으로 사용자를 조회하고, 만약 없는 사용자라면 404 에러를 띄워줘 (first_or_404 사용).
➁ 비디오 목록: 해당 사용자가 업로드한 비디오들을 최신순으로 정렬해서 가져와줘. 목록이 길어질 수 있으니 페이지네이션(pagination)을 꼭 적용해줘.
➂ 채널 통계 집계: 단순히 목록만 보여주는 게 아니라, 채널의 성적표도 계산하고 싶어. 
SQLAlchemy의 func.sum, func.count를 사용해서 아래 정보들을 변수에 담아줘.
총 조회수 합계
총 좋아요 수 합계
업로드한 동영상 총 개수
해당 채널의 구독자 수
➃ 템플릿 전송: 조회한 user, videos, 그리고 계산된 stats 데이터를 main/profile.html 템플릿으로 넘겨줘.
2. 구독 피드 (GET /subscriptions)
➀ 접근 권한: main 블루프린트에 /subscriptions 주소를 만들어줘. 여긴 로그인한 사람만 볼 수 있어야 하니까 @login_required 데코레이터를 붙여줘.
➁ 테스트 편의성: 개발 중에 매번 로그인하기 귀찮을 수 있으니까, 만약 로그인이 안 된 상태(테스트 환경)라면 임시로 첫 번째 사용자(User.query.first())의 구독 목록을 사용하도록 예외 처리를 넣어줘.
➂ 구독 기반 필터링:
먼저 현재 사용자(current_user)가 구독하고 있는 채널들의 ID 목록을 리스트로 뽑아줘.
그 다음 Video 모델에서 작성자(user_id)가 그 ID 목록에 포함된(in_) 영상들만 걸러내줘.
➃ 정렬 및 전송: 필터링 된 영상들을 최신순으로 정렬하고 페이지네이션을 적용해서, main/subscriptions.html 템플릿으로 넘겨줘.

프롬프트2 : 지금 만든 기능을 단위테스트 코드를 작성해서 확인해줘

프롬프트3 : 현재 templates/에 있는 HTML 파일들과 static/에 있는 CSS, JS 파일들을 방금 만든 Flask 백엔드 기능과 연결해줘.


6.4

프롬프트1 : 웹과 모바일 앱에서 데이터를 사용할 수 있도록 REST API와 관련 동영상 추천 기능을 만들고 싶어. 아래 조건에 맞춰서 코드를 작성해줘.
1. 비디오 API와 추천 알고리즘 (api 블루프린트)
➀ 비디오 목록 (GET /api/videos): 사용자가 page, per_page, sort, category, search 파라미터를 보낼 수 있게 해줘. SQLAlchemy의 paginate() 메서드를 활용하여 페이지 기반 페이지네이션을 구현해줘.
➁ JSON 응답 형식: 응답은 jsonify를 사용해서 {success: True, items: [...], meta: {total_pages: ..., current_page: ...}} 형태로 만들어줘. 프론트엔드에서 페이지 네비게이션을 그릴 수 있도록 메타 정보를 꼭 포함해야 해.
➂ 관련 동영상 알고리즘 (get_related_videos): 상세 조회 시 함께 보여줄 추천 함수를 별도로 구현해줘.
우선순위: 1순위는 같은 태그, 2순위는 같은 카테고리, 3순위는 같은 작성자, 마지막은 인기순(조회수/좋아요)이야.
조건: 현재 보고 있는 비디오는 제외하고, 중복 없이 limit 개수(기본 5개)만큼만 반환해줘.
➃ 비디오 상세 (GET /api/videos/<int:video_id>): 특정 비디오 정보를 조회하면 조회수를 1 증가시키고, 위에서 만든 함수를 사용해 관련 동영상 목록도 함께 JSON으로 반환해줘.
2. 태그 및 사용자 API (api 블루프린트)
➀ 인기 태그 (GET /api/tags/popular): 비디오가 가장 많이 등록된 상위 N개의 태그 목록을 뽑아줘.
➁ 태그별 비디오 (GET /api/tags/<tag_name>/videos): 사용자가 특정 태그를 클릭하면, 그 태그가 달린 비디오들만 모아서 최신순으로 보여주고 싶어.
➂ 사용자 프로필 (GET /api/users/<username>): 특정 사용자의 기본 정보와 함께 채널 통계(총 조회수 합계, 총 좋아요 수, 구독자 수)를 계산해서 반환해줘.
➃ 사용자 비디오 (GET /api/users/<username>/videos): 해당 사용자가 업로드한 비디오 목록을 가져오는 기능도 필요해. 모든 응답은 통일되게 jsonify를 사용해줘.

프롬프트3 : 현재 templates/에 있는 HTML 파일들과 static/에 있는 CSS, JS 파일들을 방금 만든 Flask 백엔드 기능과 연결해줘.
