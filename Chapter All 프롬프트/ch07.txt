Flask auth 블루프린트에 사용자가 자신의 프로필을 수정할 수 있는 기능을 구현해주세요.
Python 라우트 코드와 HTML 템플릿 코드를 모두 작성해야 합니다.

[1. 라우트 구현 (GET/POST /auth/profile)]
- 이 페이지는 로그인이 필수입니다. @login_required 데코레이터를 사용해주세요.
- [GET 요청 시]: profile.html을 렌더링하며, 폼에 현재 로그인한 사용자(current_user)의 닉네임과 이메일을 미리 채워주세요.
- [POST 요청 시 처리 로직]:
  1. 닉네임, 이메일, 현재 비밀번호, 새 비밀번호, 새 비밀번호 확인 값을 받습니다.
  2. [이메일 중복 검사]: 변경하려는 이메일이 이미 사용 중인지 확인합니다. 단, 자기 자신의 기존 이메일은 중복에서 제외되어야 합니다.
  3. [비밀번호 변경 로직]: 사용자가 새 비밀번호를 입력한 경우에만 비밀번호 변경을 진행합니다.
     - 이때 반드시 '현재 비밀번호'가 데이터베이스에 저장된 값과 일치하는지 `current_user.check_password()`로 검증해야 합니다.
     - '새 비밀번호'와 '새 비밀번호 확인' 값이 일치하는지 확인합니다.
     - 검증이 끝나면 `current_user.set_password(새_비밀번호)`를 통해 암호화하여 변경합니다.
  4. 변경된 정보를 데이터베이스에 반영(db.session.commit())하고, 성공 메시지와 함께 프로필 수정 페이지로 리다이렉트합니다.
