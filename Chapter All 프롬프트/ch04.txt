[프롬프트 2]
instance 폴더 안에 wetube.py 파일을 만들어 SQLite를 사용하여 instance/wetube.db 파일이 자동 생성되도록 구성하고 다음과 같은 table을 만들어줘.
CREATE TABLE IF NOT EXISTS users (
id INTEGER PRIMARY KEY AUTOINCREMENT,
username VARCHAR(80) NOT NULL UNIQUE,
email VARCHAR(120) NOT NULL UNIQUE,
nickname VARCHAR(80) NULL,
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

[프롬프트 4]
SQLite로 users 테이블을 만들어줘.
열(column)은 다음과 같이:
- id: 정수, 자동 증가, 기본 키
- username: 최대 80자 문자열, 필수, 중복 불가
- email: 최대 120자 문자열, 필수, 중복 불가
- password_hash: 최대 255자 문자열, 필수
- nickname: 최대 80자 문자열, 선택
- profile_image: 최대 255자 문자열, 선택
- is_admin: 불리언, 필수, 기본값 0
- created_at: 타임스탬프, 기본값 현재 시각
- updated_at: 타임스탬프, 기본값 현재 시각
username과 email에는 검색 속도를 위한 인덱스도 만들어줘.
