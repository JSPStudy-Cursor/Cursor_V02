[프롬프트 1]
Flask의 comments 블루프린트에 비디오 댓글과 대댓글(답글)을 처리하는 전반적인 기능을 구현해 줘. 다음 요구사항을 반드시 지켜서 안전하게 코드를 작성해 줘.

1. 댓글 조회 로직:
특정 비디오의 댓글 목록을 불러올 때는, 다른 댓글에 속하지 않은 최상위 댓글(parent_id가 None)만 작성 시간 오름차순으로 가져와 줘.

2. 댓글 및 대댓글 작성 기능 (Create):
일반 댓글을 작성하는 기능과, 특정 댓글에 답글을 다는 대댓글 기능(parent_id 활용)을 각각 만들어 줘.

3. 수정 및 삭제 기능 (Update / Delete)과 권한 검사:
댓글 내용을 수정하거나 지우는 기능에 본인 권한 검증 로직을 추가해 줘. 현재 로그인한 사용자(current_user.id)가 댓글 작성자(comment.user_id)와 일치하는 경우에만 처리를 허용하고, 일치하지 않으면 권한 없음 오류를 반환해 줘.

1. POST /video/<video_id>/like 라우트 작성:
- @login_required를 적용하고, video_likes 다대다 테이블을 조회해서 현재 사용자가 이미 좋아요를 눌렀으면 삭제하고, 없으면 추가하는 토글 로직을 구현해 줘.
- 처리가 끝나면 video.likes 카운트를 갱신하고 jsonify({'success': True, 'is_liked': bool, 'likes_count': int}) 형식으로 반환해.

2. GET /video/<video_id>/like/status 라우트 작성:
- 현재 사용자가 이 동영상에 좋아요를 누른 상태인지 확인하여 상태(is_liked) 정보를 JSON으로 반환해 줘.
