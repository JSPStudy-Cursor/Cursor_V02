8.1
프롬프트1 : Flask의 comments 블루프린트에 비디오 댓글과 대댓글(답글)을 처리하는 전반적인 기능을 구현해 줘. 다음 요구사항을 반드시 지켜서 안전하게 코드를 작성해 줘.
1. 댓글 조회 로직:
특정 비디오의 댓글 목록을 불러올 때는, 다른 댓글에 속하지 않은 최상위 댓글(parent_id가 None)만 작성 시간 오름차순으로 가져와 줘.
2. 댓글 및 대댓글 작성 기능 (Create):
일반 댓글을 작성하는 기능과, 특정 댓글에 답글을 다는 대댓글 기능(parent_id 활용)을 각각 만들어 줘.
3. 수정 및 삭제 기능 (Update / Delete)과 권한 검사:
댓글 내용을 수정하거나 지우는 기능을 만들어 줘.
[매우 중요] 이 기능들은 반드시 현재 로그인한 사람(current_user.id)과 댓글을 처음 작성한 사람(comment.user_id)이 정확히 일치할 때만 실행되도록 철저히 본인 확인 로직을 넣어 줘.
4. 보안 및 화면 이동 (UX):
글을 쓰고, 수정하고, 지우는 모든 라우트에는 @login_required 데코레이터를 붙여서 비회원 접근을 막아 줘.
각 작업이 성공적으로 끝나면 flash로 알림 메시지를 띄우고, 사용자가 원래 보던 비디오 시청 페이지(watch)로 자연스럽게 리다이렉트(redirect) 시켜 줘.

프롬프트1 : Flask의 likes 블루프린트에 비디오 좋아요 기능을 처리하는 두 개의 API 엔드포인트를 만들어줘.
POST /video/<video_id>/like 라우트를 작성해. @login_required를 적용하고, video_likes 다대다 테이블을 조회해서 현재 사용자가 이미 좋아요를 눌렀으면 삭제하고, 없으면 추가하는 토글 로직을 구현해 줘. 처리가 끝나면 video.likes 카운트를 갱신하고 jsonify({success: True, is_liked: bool, likes_count: int}) 형식으로 반환해.
GET /video/<video_id>/like/status 라우트를 작성해. 영상 페이지에 처음 접속했을 때 호출되며, 현재 사용자의 좋아요 여부(is_liked)와 영상의 총 좋아요 수(likes_count)를 반환해 줘. 초보자가 이해하기 쉽게 코드에 주석을 자세히 달아줘.
